# Yume Dashboard

Yume Dashboard is a pastel-themed statistics dashboard created using HTML, CSS, JavaScript and Chart.js.

The project presents data retrieved from the JSONPlaceholder API in a simple and visually appealing interface.

# Features

- Statistics cards displaying users, posts, comments and averages
- Interactive charts created with Chart.js
- Data fetched from the JSONPlaceholder API
- Light and dark theme toggle
- Custom pixel-art graphics and icons
- Interactive navigation elements

# Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js
- JSONPlaceholder REST API
- GitHub Pages
